# Predicción de Precio de Diamantes

Proyecto de regresión listo para Google Colab. Incluye EDA, modelos y SHAP.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/diamantes-precio/blob/main/diamantes_precio_colab.ipynb)

## Contenido

- EDA (distribución, boxplots, scatter, correlación)
- One-hot de cut, color y clarity
- Modelos: Ridge, Random Forest, Gradient Boosting
- Feature importance
- **SHAP** (summary + bar plot)
- Conclusiones

Dataset: seaborn diamonds

Rango esperado: R² ~0.96–0.98 | MAE ~300–400
